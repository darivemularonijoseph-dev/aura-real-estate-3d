# THE AURA RESIDENCES — 3D Real Estate Architectural Showcase 🏛️

A high-converting, ultra-luxury 3D scrollytelling real estate landing page inspired by high-end architectural showcases (similar to Sotheby's Realty, Architectural Digest, and Dubai/Beverly Hills developments).

## 🌟 Key Features

1. **Procedural 3D Architectural Villa**:
   - Built natively with **Three.js** with zero external file dependencies or CORS issues.
   - Features cantilevered concrete volumes, realistic glass reflectivity, warm interior architectural point lighting, floating reflection pool with water motion, and ambient floating gold dust particles.
2. **GSAP ScrollTrigger Scrollytelling**:
   - Camera smoothly orbits around the villa across 4 phases as you scroll down:
     - **Phase 0 (Hero)**: Wide dusk cinematic view with property statistics.
     - **Phase 1 (Cantilever)**: Zoomed architectural exterior view.
     - **Phase 2 (Sanctuary)**: Warm interior living focus.
     - **Phase 3 (Sky Deck)**: Sunset aerial overview with private booking callout.
3. **Curated Amenities Bento Grid**:
   - High-contrast luxury bento grid showcasing smart AI home integration, vitality spa, automobile gallery, and sommelier cellar.
4. **Interactive Acquisition & Mortgage Calculator**:
   - Real-time loan modeling with sliders for down payment ratio, term, and interest rate.
5. **VIP Concierge & WhatsApp Booking**:
   - Confidential booking modal and direct one-click WhatsApp concierge link.
6. **Responsive Design**:
   - Tailored for desktops, tablets, and smartphones with mobile drawer navigation.

## 🚀 Quick Start / How to Run

No `npm install` or build step required! Everything is self-contained.

1. Clone or download this repository.
2. Double-click `index.html` to open it in Chrome, Edge, or Safari.

---

## 🛠️ Deploy to GitHub Pages or Vercel (1-Click)

### Option A: GitHub Pages
1. Push this repo to your GitHub account.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live instantly!

### Option B: Vercel
1. Import this repository on [Vercel](https://vercel.com).
2. Click **Deploy** (no build command needed).
